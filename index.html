Settings

Proxy on (deployed): calls go through the Vercel function, which holds the key as a server env var. Nothing sensitive reaches the browser, and there is no CORS problem. Base URL and key below are ignored.

Proxy off (local dev): the page calls chestbox directly. That needs a CORS layer on chestbox, and the key is kept in sessionStorage where anyone with this browser can read it — use a throwaway key, never a production one.
